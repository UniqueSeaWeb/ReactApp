# React ToDo アプリ ＆ 3D コンテンツ ＆ フットサル大会

React + Vite で作成した 4 つのページからなる Web アプリです。

- **フットサル大会メーカー**（`/futsal/`）: 大会ごとの URL で対戦表・得点・順位を共有する大会運営アプリ
- **ToDo アプリ**（`/`）: シンプルな ToDo 管理
- **太陽系ビューア**（`/solar/`）: three.js で描いた 3D の太陽系
- **WIRE BLADE 巨人討伐**（`/titan/`）: 立体機動で巨人と戦う 3D アクションゲーム（スマホ横持ち対応）

## フットサル大会メーカー

誰でも自分のフットサル大会を作り、発行された URL を共有するだけで、対戦表・得点入力・順位表をスマホと PC から使えます。

### 機能

- **大会の作成**: 大会名（重複不可。全角半角・大文字小文字の違いも同一とみなす）・主催者・開催日・管理者パスワード・参加者用の合言葉を入力すると、大会ごとの URL（`/futsal/#/t/<ランダムな 12 文字>`）を発行
- **閲覧（ログイン不要）**: 大会情報、対戦表（チームで絞り込み可）、試合詳細（得点者）、チーム順位、個人得点ランキング、チームのメンバー
- **参加者（合言葉でログイン）**: チームを選んでメンバー（背番号・名前）の登録・修正・削除、試合の得点者の入力・取消、試合終了の設定
  - オウンゴールは **点が入った側** のチームで「オウンゴール（相手選手）」を選んで入力（個人得点には数えない）
- **管理者（パスワードでログイン）**: 参加チームの登録・修正・削除、大会情報の修正、対戦表の自動作成、参加者の機能すべて
- **対戦表の自動作成**: エントリーチーム・開始日時・試合時間・インターバル・コート数・コート名・1 チームあたりの試合数を入力すると、総当たり（サークル方式）を基に **全チームの試合数が均等**（奇数チームで割り切れない場合のみ差 1）になるよう組み合わせ、同じ時間帯の重複なし・連戦をできるだけ避けて各コートに割り当て。ホーム／アウェーも偏らないよう調整し、作成前に試合数と終了予定時刻をプレビュー
- **チーム順位**: ポイント ＝ 勝ち点（勝 3・分 1・負 0）÷ 試合数。同ポイントは得失点差 → 総得点。「試合終了」にした試合のみ集計
- **個人得点ランキング**: 通算得点（同数は同順位）
- 表示中は 30 秒ごと・画面に戻ったときに最新の状態を再取得

### 構成

- **フロントエンド**: GitHub Pages（静的ホスティング）。サーバー側ルーティングがないためハッシュ（`#/...`）で画面遷移
- **データ保存**: [Supabase](https://supabase.com/)（PostgreSQL）。GitHub Pages だけでは複数人でデータを共有できないため、DB 側の RPC 関数（`supabase/schema.sql`）経由で読み書きする
- **デモモード**: Supabase の接続先が未設定のときは、データをこの端末の `localStorage` にだけ保存して動作（画面上部に表示）

### セットアップ（Supabase）

1. Supabase でプロジェクトを作成し、SQL Editor で `supabase/schema.sql` を実行（再実行可）
2. Project Settings → API の **Project URL** と **anon public key** を控える
3. GitHub リポジトリの Settings → Secrets and variables → Actions → **Variables** に `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` を登録（anon key は公開前提の鍵。テーブルへの直接アクセスは SQL 側で遮断済み）
4. `main` へプッシュすると接続先が埋め込まれてデプロイされる。ローカルでは `.env.example` を `.env.local` にコピーして値を設定

### セキュリティ

- テーブルは `anon` から直接読み書きできない（権限剥奪＋RLS 有効・ポリシーなし）。操作はすべて `SECURITY DEFINER` の RPC 関数で、入力値の長さ・件数上限・所属（他大会の ID を指定した改ざん）を DB 側で検証
- パスワード・合言葉は bcrypt でハッシュ化して保存。ログイン成功時に発行するセッショントークンは DB に SHA-256 のみ保存し 12 時間で失効、ブラウザでは `sessionStorage`（タブを閉じると消える）に保持
- ログイン失敗は大会ごとに 15 分 10 回まで（総当たり対策）
- 権限チェックはすべてサーバー側。画面上の「管理」タブの表示切り替えは見た目だけで、権限の根拠にはしていない
- 本番ビルドでは `Content-Security-Policy`（meta）でスクリプト・通信先を自サイトと Supabase に限定。React のエスケープに任せ、`dangerouslySetInnerHTML` は不使用
- 残るリスク: 大会作成はだれでもできる（スパム対策が必要なら Cloudflare Turnstile などの導入を推奨）／ロックは大会単位のため、第三者がわざと失敗を重ねると 15 分間ログインできなくなる

### Web 標準・アクセシビリティへの配慮

- ログインはネイティブの `<dialog>`（`showModal()`、Esc・戻る操作・外側タップで閉じる）
- すべての入力欄に `label`、補足説明は入力欄の上に置き `aria-describedby` で関連付け。エラー表示は `:user-invalid` で入力後にだけ出す
- 2 択（得点チーム）はラジオボタン、多数の選択肢は `<select>`。送信中は `fieldset disabled` で二重送信を防止
- 通知は `role="status"`、エラーは `role="alert"`。タブは `nav` 内のリンクで現在地に `aria-current="page"`
- 順位表は `th scope` 付きの `<table>`。スマホでは枠内で横スクロール（チーム名の列は固定、キーボードでもスクロール可）
- タップ領域 44px 以上、入力文字 16px 以上（iOS の自動拡大防止）、ライト／ダークモード、`prefers-reduced-motion` 対応

## WIRE BLADE 巨人討伐

城壁に囲まれた街と巨大樹の森を、ワイヤーとガスで飛び回り、巨人のうなじを斬る 3D アクションゲームです。特定の作品の名称・キャラクター・ロゴは使わず、「立体機動で巨人を斬る」遊びを取り入れたオリジナル作品として作っています。

- **遊び方**: ワイヤーを建物・木・巨人に刺して巻き取り、振り子の勢いとガス噴射で加速。うなじに近づくと照準が橙色になり、そこで斬ると討伐。全 5 波を退けるとクリア
- **操作（スマホ横持ち）**: 左スティックで移動、右側ドラッグで視点、アンカー（長押し）・ガス（長押し）・斬る。アンカーやガスを押したまま指を滑らせても視点を回せる。視点を動かしていないときはカメラが進行方向へ自動で向く
- **操作（PC）**: WASD、マウス（ポインターロック）、Space / 右クリックでアンカー、Shift でガス、左クリック / F で斬る、Esc で一時停止
- **グラフィック**: 大気散乱の空シェーダー、指数フォグ、リアルタイムの影（PCF ソフトシャドウ）、ACES トーンマッピング、高画質ではブルーム。建物・木・山はインスタンシングで描画し、テクスチャはすべて Canvas で生成（画像ファイルなし）
- **演出**: ガス・蒸気・火花のパーティクル、斬撃の軌跡、討伐時のスローモーションと画面の揺れ、速度に応じた視野の拡大と集中線、Web Audio で合成した効果音
- **配慮**: 画質の切り替え（高画質／標準）、縦持ち時の案内、`prefers-reduced-motion` でスロー・揺れ・視野変化・集中線を停止、HUD のガス残量は `<meter>`、状況の変化は `role="status"` で読み上げ

## 太陽系ビューア

three.js（`@react-three/fiber` / `@react-three/drei`）で、太陽と 8 つの惑星の公転を 3D で表示します。

- ドラッグで回転、ホイールやピンチで拡大縮小
- 天体をクリック、または一覧から選ぶと、その天体へ近づいて直径・距離・自転/公転周期・解説を表示（Esc で全体表示に戻る）
- 再生／一時停止、速さ（1 秒 = 1 日〜約 1 年）、今日に戻す、軌道線・名前の表示切り替え
- 惑星の模様は画像を使わず Canvas で生成
- 大きさと距離は見やすさのために縮めて表示（数値は NASA Planetary Fact Sheet を丸めた値）
- `prefers-reduced-motion` が有効なら一時停止で始まり、カメラの移動アニメーションも省略
- 3D 表示には説明文（`role="img"` と `aria-label`）を付け、天体の選択はすべてボタンからも操作可能

## ToDo アプリ

### 機能

- タスクの追加・完了切り替え・削除（削除は「元に戻す」で取り消し可能）
- 完了の割合を示す進捗バー
- 「すべて / 未完了 / 完了」の表示切り替え（件数付き）
- 完了済みタスクの一括削除
- `localStorage` によるデータの保存
- ライト / ダークモード、スマホ表示に対応

### Web 標準・アクセシビリティへの配慮

- `lang="ja"` の指定、`header` / `main` / `nav` / `section` / `footer` によるセマンティックなマークアップ
- すべての入力欄に `label` を関連付け
- フィルタボタンは `aria-pressed`、件数表示は `role="status"` で支援技術に状態を通知
- 進捗はネイティブの `<progress>` 要素、削除の通知は `role="status"` のトーストで伝達
- `:focus-visible` によるキーボードフォーカスの可視化、タップ領域 44px 以上
- `prefers-reduced-motion` でアニメーションを停止
- 色・余白・角丸などは `:root` のデザイントークンで一元管理
