アプリ一覧

React + Vite で作った Web アプリです。遊びたいものを選んでください。

  • ToDo アプリ タスクの追加・完了・削除。データはこのブラウザに保存されます。 スマホ / PC
  • 3D 太陽系ビューア 太陽と 8 つの惑星の公転を 3D で。惑星を選ぶと大きさや公転周期を表示します。 スマホ / PC ・ 3D
  • WIRE BLADE 巨人討伐 ワイヤーとガスで街と森を飛び回り、巨人のうなじを斬る立体機動アクション。 スマホ横持ち / PC ・ 3D ゲーム
  • フットサル大会メーカー 大会を作って URL を共有。対戦表の自動作成、得点入力、順位表まで。 スマホ / PC
